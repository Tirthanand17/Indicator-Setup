# NIFTY Five-Indicator Paper Alerts — Chrome MV3 beta

**Status: prototype, not a live signal feed.** This is a **₹0**, no-server browser extension designed for Zerodha Kite's NIFTY futures TradingView chart. It automatically recognizes that a Kite chart tab is open, but **does not yet automatically extract reliable closed-candle indicators**. Indicator/option readings are entered and confirmed manually for this version. It then performs the decision checks and can send desktop notifications. Do not use it for live order decisions without independent verification.

## Install

1. Get the `extension/` folder from the [Indicator-Setup GitHub repository](https://github.com/Tirthanand17/Indicator-Setup). Keep all files together.
2. In Google Chrome, open `chrome://extensions` in a separate tab, enable **Developer mode**.
3. Click **Load unpacked**, and select the **extension folder itself** (not the repository's root).
4. Pin **NIFTY Five-Indicator Paper Alerts** to the Chrome toolbar.
5. Open the existing **NIFTY current-month futures** 5-minute chart on Kite. Verify session VWAP HLC3, EMA9, EMA21, DMI14/14 (+DI, −DI, ADX), ATR14, nonzero futures volume.
6. Open the extension popup → **Signal Dashboard**. The chart should say **DETECTED** after up to 12 seconds. This confirms **presence only**.
7. Optionally click **Send TEST notification**, and allow OS/Chrome notifications. Switch on **Enable local desktop notifications**. Submit **manually verified closed-candle values**; only aligned candidate observations can notify. No notifications are generated by just keeping the chart open.
8. For a paper position, enter bought CE/PE premium, premium stop and premium target. Manually enter its current option **BID** to check an exit. Exits cannot be monitored automatically without an independently verified quote feed.

## Safety and privacy

- **NEVER places trades**; no permissions for orders, account balance, Kite cookies, login tokens, browser downloads or external HTTP requests.
- The content script scans only chart **pathname** to detect Kite tabs. It intentionally **never reads, logs, sends or stores the iframe URL fragment/hash**, because Kite may put session credentials there.
- Host permission is restricted to `https://kite.zerodha.com/*`; data stays in local extension storage; no analytics server, tracking or paid plan.
- Fail closed on zero volume, stale data (>12 minutes), not a completed 5-minute candle, invalid values, off-session date/time, no chart, conflicting filters, missing option verification, weak ADX or near VWAP (within 0.1×ATR). Holidays and expiry contract eligibility must be verified separately.
- Uses ADX > or = 25 **and rising**. This is an **unvalidated research heuristic**, not a promise of profitability.
- One CE/PE desktop alert maximum per futures symbol + completed candle + direction; no desktop alert for NO_TRADE by default.
- OS notifications are **potential setups, not trading recommendations**. They never mean buy/sell automatically.
- The exit checker uses **manually entered option BID** only; cannot monitor a real position in Kite.

## Roadmap for truly automatic live alerts

1. **Approved authenticated read-only live candles and option bid/ask feed** with explicit user authorization and verified pricing. At the time of writing, Zerodha's official market streaming/historical API is not in the ₹0 Personal tier. Do not activate paid API without approval.
2. Independently calculate session VWAP, EMA9, EMA21, DMI/ADX14 and ATR14 from actual timestamped NIFTY futures OHLCV; confirm completed five-minute bars and fifteen-minute context.
3. Strict data freshness, session, volume, option liquidity, spread, expiry, slippage, ATR risks; notify only with validated signals. No broker execution.
4. Backtest with actual option quote snapshots and costs before considering real trading; measure expectancy and drawdown, not just win percentage.
5. If true laptop-independent alerts become necessary, use a separate cloud service plus approved source and an appropriate budget; this MV3 extension stops when Chrome/laptop are closed.
